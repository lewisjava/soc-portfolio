# Access to Higher Education Diploma — Computer Science (Level 3)

**Awarding body:** AIM Qualifications and Assessment Group
**Provider:** MC Digital
**Level:** 3 — recognised as equivalent to A-levels
**Duration:** One year, September 2022 – 2023

## Overview

A Level 3 Access to Higher Education Diploma in Computer Science, delivered as a full-time adult learner course. Access to HE Diplomas are QAA-regulated qualifications designed as an alternative route into higher education for adult learners, and are recognised by UK universities and employers as equivalent to A-levels.

## Modules

- Computer Systems
- Cyber Security
- Database Applications
- Introduction to Computer Architecture
- Introduction to Programming
- Systems Analysis and Design
- Maths for Computing
- Web Page Design and Production

## Relevance to security work

Several modules map directly onto foundations that later security study builds on. **Computer Systems** and **Introduction to Computer Architecture** cover how operating systems and hardware actually work — the layer beneath endpoint detection and log analysis. **Cyber Security** provided the first structured introduction to the field. **Database Applications** and **Introduction to Programming** underpin later work with query languages such as SPL and KQL, and with scripting for log parsing and automation.
